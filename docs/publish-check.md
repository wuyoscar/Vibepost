# 发布检查与字体许可

发之前帮你少出错：页脚页数旁的「检查 · N」列出这篇里可能出问题的地方（标题、标题下面「正文」栏里的小红书正文、卡片内容都查），卡片内容里的同时画线标出；点「发送到 iPhone」时先查一遍，还有提醒就问一句。全部在本机比对，不联网。

实现：规则在 `src/publish/check.js`（纯函数），词库在 `src/publish/lexicon.json`，界面与发送前的确认在 `src/publish/assistant.js`，卡片内容里的标注在 `src/editor/hints.js`。测试：`macos/Tests/MediaCraftShellTests/PublishAssistantTests.swift`、`CaptionTests.swift`。

> 这是写稿时的提醒，不是法律意见。词库只收常见的说法，查不出来不代表没有问题；命中了也不一定违规（比如「最好先洗脸」里的「最好」），所以每一条都可以忽略。

## 查什么

| 分组 | 级别 | 规则 |
| --- | --- | --- |
| 数量上限 | 警告 | 标题超过 20 字（按显示宽度，见下）；正文栏超过 1000 字（空白不计）；正文栏里的 `#话题` 超过 10 个（去重，跳到第一个发不出去的；卡片内容里的不算）；卡片超过 18 张。长文模式不查这几项 |
| 正文 | 提示 | 正文栏还空着：「正文还没写」。小红书图片下面的那段在标题下面的「正文」栏里单独写，发送时它进剪贴板。只在检查面板里列，发送前不因它弹确认（空着也能发，提示卡会说剪贴板没动）。长文模式不查 |
| 署名 | 提示 | 署名的名字还空着：「署名还没填」。卡片上只有头像、没有名字，在「样式 › 署名」里填（也可以就这样发）。只在检查面板里列，发送前不因它弹确认。长文模式不查 |
| 极限词 | 警告 / 提示 | 「国家级」「最佳」「全网第一」「最低价」……这类绝对化用语 |
| 医疗用语 | 警告 / 提示 | 「根治」「无副作用」「100% 有效」……治疗功能与功效保证 |
| 收益承诺 | 警告 / 提示 | 「保本」「稳赚」「零风险」……保证收益的说法 |
| 引流 | 警告 / 提示 | 「加微信」「vx」「二维码」「淘口令」、手机号、座机号、QQ 号、网址、邮箱，以及提到别的平台、「私信我」 |
| AI 声明 | 提示 | 这篇用过 AI 助手（会话里有过一轮，包括插进来的配图候选）：发布时在小红书勾选「笔记含 AI 合成内容」 |

**警告**是大概率会被限流、下架或违反法规的说法；**提示**是常被误判、要看上下文的（「唯一」「绝对」「治疗」「淘宝」）。

每一条可以：点它**跳过去**（卡片内容里的在编辑器里选中那几个字，标题里的跳到标题框，正文栏里的展开正文栏并选中）；**替换**（词库给了改法的是「改成『很好』」，引流与联系方式是「删掉」；没有通用改法的只能自己改），卡片内容里的替换是撤销历史里的一步，⌘Z 撤回；**忽略**（这篇里不再提醒同样的字，记在本机，面板底部可以「恢复忽略的 N 处」）。

**发送前**：点「发送到 iPhone」时查一遍，还有提醒就问「还有 N 处提醒，仍然发送？」，列出每组命中的字；「去看看」打开检查面板、不发送，「仍然发送」照常发。勾「不再提醒」以后发送前不再查，检查面板底部的「发送前自动检查」可以重新打开。只管界面上的按钮：App API 的 `output.sendToIPhone()`（测试、AI、MCP）直接发。

**发完以后**：「已交给隔空投送」的提示卡留着等你关，上面有「复制标题」「复制正文」「复制话题」三个按钮（正文照样已经在剪贴板里）：经 Mac 与 iPhone 的通用剪贴板，在小红书里依次粘进标题栏、正文与话题。正文是正文栏里的那段（长文没有正文栏，是全文的纯文本）；话题是正文里的 `#话题`，再接上 AI 助手快捷命令最近一次回复里建议的，去重后写成 `#甲 #乙`；没填标题、正文、没有话题时对应的按钮停用。正文栏空着时剪贴板不动，提示卡上写明。

## 标题怎么计字

按小红书的显示宽度：中文、全角符号（「，」「：」“”……）与每个 emoji（按字形算，👍🏽、🇨🇳 都是一个）算 1 个字，英文字母、数字、半角符号与空格算半个字，半个字向上取整；首尾空白不算。标题框右边显示 `x/20`，超过时标红。正文栏右边的 `x/1000` 数的是正文栏（小红书正文）本身：空白不计，emoji 这类增补平面字符算 2 个字；卡片上的字不算。

## 怎么比对

- **只查看得到的字**：卡片内容按解析树（`src/engine/markdown.js`）取出标题、段落、引用、列表、表格里的文字。Markdown 标记（`**`、`{{color:…|`）、图片与分页标记、行内代码与代码块都不查；标题框里的标题、正文栏的整段纯文本也查（图文卡片模式）。同一组里标题在前，正文栏其次，卡片内容按位置。
- **网址**：正文里的网址整条算一处「网址」，里面的字不再单独算；Markdown 链接 `[文字](网址)` 的网址不在卡片上，但复制出去的正文里有，所以链接文字整段算一处。
- **中文按字比对**：词出现在哪里都算，比如「全网最低价」里的「全网最低」。「第一」只在讲排名时算：后面接次、步、天、时、章、页、张……这类表示顺序的字时跳过（第一次、第一步、第一时间）。
- **西文要整词**，不分大小写：`vx` 不会在 `vxworks` 里命中，`QQ号` 里的 `QQ` 会。
- **同一处只算一条**：几条规则命中重叠的字时，留最先开始、最长的一条（「加微信」不会再算一次「微信」）。

## 词库

`src/publish/lexicon.json` 是我们自己按下面的出处整理的，没有抄任何查词工具的词库。改词库不用改代码：

```jsonc
{
  "categories": [{ "id": "absolute", "label": "极限词" }, …],   // 分组；「数量上限」「正文」「AI 声明」是代码里的
  "rules": [
    {
      "category": "absolute", "level": "warn",               // warn 警告 / hint 提示
      "reason": "广告法第九条：…",                            // 面板里每条下面那一行
      "words": { "最佳": "很好", "国家级": "", "唯一": null } // 词 → 建议改成的字；"" 是删掉，null 是没有通用改法
    },
    {
      "category": "traffic", "level": "warn", "reason": "…",
      "name": "手机号",                                       // 面板里显示的名字
      "pattern": "(?<!\\d)1[3-9]\\d(?:[- ]?\\d{4}){2}(?!\\d)",  // JavaScript 正则，按不分大小写、Unicode 模式用
      "suggest": ""
    }
  ]
}
```

- 同一条规则里的词按长短排进一个正则，长的先匹配；西文开头或结尾的词自动加上整词边界。
- `pattern` 规则的 `name` 同时用来比对链接的网址（从头匹配），所以「网址」「邮箱」两条也管 Markdown 链接。
- 加词时写清楚 `reason` 里的依据；拿不准的放「提示」。

## 出处

- 《中华人民共和国广告法》（2021 年修正）[全文（北京市市场监督管理局）](https://scjgj.beijing.gov.cn/cxfw/flfgcxfw/ggl/202204/t20220401_2646388.html)：
  - 第九条第（三）项：不得使用「国家级」「最高级」「最佳」等用语 → 极限词；
  - 第十六条第一款第（一）（二）项：不得有表示功效、安全性的断言或者保证，不得说明治愈率或者有效率 → 医疗用语里的「100% 有效」「无副作用」；
  - 第十七条：除医疗、药品、医疗器械广告外，禁止其他任何广告涉及疾病治疗功能，不得使用医疗用语 → 医疗用语；
  - 第二十五条第一款第（一）项：不得对未来效果、收益作出保证性承诺，明示或者暗示保本、无风险或者保收益 → 收益承诺。
- 国家市场监督管理总局《广告绝对化用语执法指南》（2023 年第 6 号公告）[原文](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/ggjgs/art/2023/art_64279265c896452f8f638f2de12b8003.html)：绝对化用语包括「与其含义相同或者近似的其他用语」；只表示经营理念、目标追求，或者在限定时间、地域下陈述时空顺序的客观情况不算 → 「第一次」「第一步」跳过，「最好」「唯一」只作提示。
- [《小红书社区规范》](https://agree.xiaohongshu.com/h5/terms/ZXXY20221213003/-1) 与 2025 年 3 月起施行的《交易导流违规管理细则》（[网经社报道](https://www.100ec.cn/detail--6647740.html)）：不得发布个人或企业的电话、手机号、QQ、微信、淘宝店铺链接与淘口令、二维码等站外联系方式，不得引导用户到站外交易 → 引流。
- 国家网信办等四部门《人工智能生成合成内容标识办法》（2025 年 9 月 1 日起施行）[原文](https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm)：AI 生成合成的内容要标识 → AI 声明提醒。

## 字体许可

字体选单里每一项右边标出许可：

| 标注 | 是哪些 | 说明 |
| --- | --- | --- |
| OFL 可商用 | 全部打包字体：思源黑体、思源宋体、霞鹜文楷、得意黑、Inter、IBM Plex Sans / Serif / Mono、Source Serif 4、JetBrains Mono、Fira Code | 按随字体下载的许可证文本（`scripts/fetch-fonts.py` 从各字体的 npm 包与发布仓库取来，放在 `fonts/licenses/`）逐个核对过，都是 SIL Open Font License 1.1：可以免费商用，排出来的图不受限制 |
| 系统字体 · 仅限个人 | 苹方、宋体、SF、Georgia、Menlo | macOS 自带，授权只随这台 Mac；拿去做商用的图要另外取得授权 |

「跟随主题」不标：12 个主题用的都是打包字体。许可记在 `src/themes/fonts.js` 每个选项的 `license` 上（`ofl` / `system`），App API `fonts.list()` 的每项也带着它。

导出（单张、整组、长图）与发送时，这篇用到系统字体（中文、英文字体，有代码时还有代码字体）就在进度卡片上提醒一次：同一篇、同样的字体这次打开 App 里只提醒一次，换了字体再提醒；点「不再提醒」以后都不提醒。复制公众号格式不提醒（粘过去的是文字，用的是读者手机上的字体）。
