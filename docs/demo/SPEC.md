# 主视频：你写，Agent 排

```text
GOAL:    看完的人记住一句话：在 Vibepost 里，我写字，Agent 帮我排版、配图，我点头它才改；终端里的 Agent 也能连进来。
OUTPUT:  HyperFrames，1920 x 1080，30 fps；配乐版 + 无声版
TIME:    73.5 s x 30 fps = 147 拍；成片 120 BPM，一拍 15 帧，一小节 60 帧；点击落在拍子上。
         排的时候按 96 BPM、一秒 24 帧算，放的时候一秒 30 帧：整条片子快 1.25 倍（下面 MOTION 里的秒数是排的时候的，成片里乘 0.8）
LOOK:    舞台就是 App 自己：浅灰底 #f2f2f4（App 窗口外的地面），界面截图原色不加滤镜。
         墨 #16171a：所有要读的字。强调色只有一个：App 图标的橙红 #ff4f1f，一个镜头最多一处（点击时的圈、关键词下划线）。
         标题字：PingFang SC Semibold 120 px（画面高 11%）与 96 px，字距 -1%；说明 44 px，快进角标 30 px。不用衬线、不用等宽小标签。
         材质：真实界面的截图（2 倍像素，2880 x 1620），卡片是 App 真出的 PNG（1728 x 2304）。
         景深：浮起来的东西（面板、飞的图、手机）投影 0 24 px 60 px、22% 黑；地面不加颗粒、暗角、渐变。
OBJECTS: 面板（一块录屏的窗口，里面有自己的镜头）；会话里 Agent 的每一步（真实文字）；配图候选（Agent 真生成的图）；
         修改对比（编辑器里的标注、「全部接受」）；终端（Codex 的真实输出：它说的话和它经 MCP 调的工具）；
         iPhone（黑边、圆角 66 px、灵动岛，屏幕里只放这篇的卡片、标题和正文，不仿任何 App 的界面）；App 图标 brand/icon.png。
MOTION:  到达：expo.out 0.5–0.7 s；面板移动、分开、并拢：power3.inOut 0.7 s；离开：power3.in 0.3–0.45 s（比到达短）。
         镜头：每块面板里一个，临界阻尼弹簧（ω = 9）追着被跟踪的元素（录制时逐帧记了位置），面板里永远铺满不露底。
         光标：画出来的，68 px，从画外进，走弧线；点下去缩到 0.82、0.22 s 回弹，同时一个橙红的圈；点击的下一帧出结果。
         转场都由画面里的东西引起：窗口自己摆正、放大；点开「AI 助手」后一块面板分成两块；点配图候选，图飞进卡片；
         光标拖着一条线擦出「之前」；窗口滑出、终端和新窗口滑入；卡片从舞台飞进手机；手机收成图标。不用淡入淡出。
         Agent 在想的时候快进，右下角标「快进 ×N」，N 是真实的倍数（录制时每帧记了时刻）。
SHOTS:   （成片的拍号；一拍 0.5 s）
  0–8      HOOK    首帧就有主体：「写完了。」和窗口（微微倾斜，里面是一整屏没排过的字）。第 2、3、4 拍压进「还要排版、」「配图、」「分页。」
  8–14     TENSION 字被窗口顶走；窗口摆正、放大到工作位，镜头推到舞台上那张全是字的卡片；光标进来点「下一张」，下一页也全是字。
  14–20    REVEAL  「Vibepost：你写字，Agent 排版。」光标点「AI 助手」；面板分成两块：左边是你的卡片，右边是和 Agent 的对话。
  20–30    说一句    右边对着对话框，那句话一个字一个字出现（真实那句）；光标点发送，镜头跟到会话里的那句。
  30–44    Agent 动手 右边是会话里 Agent 的每一步（真实文字），左边的卡片同时变样：换主题、分页、套组件；配图候选一张张出来。快进。
  44–52    你点头    左边换成编辑器里逐处标出的修改；右边光标点「全部接受」。
  52–67    配图      三次，一张五拍：左边翻到那道菜的一页，光标在右边点那张候选图，图飞进卡片落位，在带图的那一页上停两拍多。
  67–73    之前/现在  光标在左边的卡片上拖出一条线：线左边是开头那张没排过的，右边是现在的。
  73–83    自己调    右边换成「样式」：光标换两个主题再换回来，图文尺寸换成 9:16 再换回，按着滑块把图片拖大再拖回来；左边的卡片跟着变。
  83–97    长本事    右边发出「给这篇写一套自己的卡片样式」，快进；左边的卡片换了样子，再一页一页翻过去。
  97–105   写作手册  两块并回一块；光标点「存成我的写作手册」，快进，确认框弹出，光标点「保存」。
  105–119  终端      窗口滑出；终端（左）和 Codex 经 MCP 新开的窗口（右）滑入。终端里一行行出来的是真实输出，右边稿子跟着长出来，最后翻三页。
  119–133  PAYOFF   终端、窗口滑出；窗口（左）和 iPhone（右）进来；光标点「发送到 iPhone」，卡片按页序一张张飞进手机。
  133–139  CLAIM    窗口滑走；「你写字。」「Agent 排版。」「你点头。」一拍一句。
  139–147  END      手机收成 App 图标，移到中间；「Vibepost」压进来，下面是仓库地址，停 3 s。
BANNED:  深色空底上飘小界面；光晕、粒子、渐变；把截图压暗再压标题；每个元素都淡入上滑；字落定后还在动；三张卡片并排当功能列表；
         logo 挂在角上；编号「01 / 02」、角标、边框装饰；胶囊形的小标签；打字进输入框当开场；假的界面、画出来的按钮；
         一个镜头里同时有两处强调色；画面内容不是真实录到的（Agent 的话、生成的图、终端输出都要是那次真跑出来的）。
QA:      0 s 的首帧有主体；每段开头后 0.5 s 一帧；每次转场前后各两帧；快进角标只在快进时出现；字 ≥ 28 px 且在 80% 安全框里；
         最后一帧是片尾；配乐 -17 LUFS 左右、峰值 ≤ -1 dBTP，交付时写明没试听过。
```

素材：`macos/Tests/MediaCraftShellTests/DemoFramesTests.swift` 的 `collab`（App 里的 Agent，本机 Codex）与 `agent`（终端里的 Codex 经 MCP）两段，
逐帧截界面，同时记下关键元素在每一帧的位置（会话、舞台卡片、配图候选、修改对比），合成时据此把面板单独拎出来放大；成品卡片取自发送到 iPhone 时（假的接收端）收到的 PNG。
