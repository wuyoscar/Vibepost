# 教程视频的三条故事线

一件事：用 Markdown 写一篇小红书笔记，Vibepost 把它排成卡片，发到手机。
一个人做一件真事：一篇「周末去山里看一次日出」，从打第一行字到隔空投送。

## A. 一篇笔记从写到发（采用）

- 做法：整段是同一个窗口里的真实操作，镜头跟着指针推近到正在用的那一块，一步一句大字。
- 前两秒：窗口全景，稿子已经有标题和第一段，底下一行字「一篇小红书笔记，从写到发」。
- 节拍：全景 → 写 → `/` 插图 → 换主题 → 封面 → AI 改动逐处确认 → 检查与手机预览 → 发送 → 一句话收尾。
- 样子：界面本身就是画面，铺满；字是墨色块上的白字，压在左下。
- 声音：一段轻的合成音乐，另留无声版。

选它的原因：教程要的是照着能做，一个例子从头走到尾最好跟。

## B. 先看结果

成品的六张卡片先在手机里滑一遍，镜头拉回到电脑上的窗口，再倒回去看它是怎么写出来的。开头更抓人，但前十秒观众还不知道这是个什么工具。

## C. 卡片自己讲

每一句讲解本身排成一张 3:4 的卡片，卡片翻过去露出对应的界面。形式和产品是同一种东西，但界面被缩进卡片里，按钮看不清，不适合教程。

## 2026-11-16 重来：主视频改成「人机协作」

第一版教程（上面的 A）被否：没有动效感、卡片全是字没有图、润色前后看不出差别、没打出「Agent 是底座、人机协作排版」这一点。
新的三条（都以人机协作为主线，60–75 秒）：

- **A 你写，Agent 排**（采用）：一堆没排过的字 → 人在对话框说一句 → Agent 分页、换样式、自己生成配图、挑主题 → 修改逐处亮起，人点头 → Agent 写一套新的卡片样式、把写法存成写作手册 → 分屏：终端里的 Claude Code 经 MCP 连进来再排一篇 → 卡片按页序落进 iPhone。
- **B 先看结果**：一面成品卡片墙，镜头飞进一张，它长成 App 窗口，倒着演人和 Agent 怎么一起做出来，最后墙变成手机相册。
- **C 底座**：把 App 拆成几层（操作手册、写作技能、写作手册、App 工具、MCP），每一层在 Agent 用到时亮起。

原来按功能讲的两分钟教程留作详细教程，用带配图的稿子重录，补上实况与声音（SPEC-tutorial.md）。
