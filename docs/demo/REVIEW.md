# 主视频「你写，Agent 排」：交付说明（2026-11-16）

成片：`docs/screenshots/vibepost.mp4`（配乐）与 `docs/screenshots/vibepost-silent.mp4`（无声），1920 × 1080、30 fps、H.264 yuv420p、faststart，83.7 秒。分镜与规格见 `SPEC.md`。

## 里面有什么

| 时间 | 镜头 | 内容 |
| --- | --- | --- |
| 0–5 s | 开头 | 「写完了。还要排版、配图、分页。」窗口里是一整屏没排过的字 |
| 5–12.5 s | 现状、点题 | 窗口摆正，镜头推到全是字的卡片；「Vibepost：你写字，Agent 排版。」光标点开 AI 助手，面板分成两块 |
| 12.5–19 s | 说一句 | 对话框里打出那句要求，发送 |
| 19–27.5 s | Agent 动手 | 右边是 Agent 的每一步，左边的卡片同时变样；三张配图候选出来。快进 ×14 |
| 27.5–32.5 s | 你点头 | 编辑器里逐处标出的修改，光标点「全部接受」 |
| 32.5–40 s | 配图 | 三次：点一张候选图，图飞进那道菜的一页 |
| 40–44 s | 之前 / 现在 | 光标在卡片上拖一条线，线左边是开头那张没排过的 |
| 44–52.5 s | 写卡片样式 | 让 Agent 给这篇写一套卡片样式（快进 ×8），再逐页翻过去 |
| 52.5–57.5 s | 写作手册 | 「存成我的写作手册」，确认框，保存 |
| 57.5–66 s | 终端 | 终端里的 Codex 经 MCP 新建一篇、分页、换主题（快进 ×18），翻三页 |
| 66–75 s | 发到 iPhone | 点「发送到 iPhone」，三张卡片飞进手机 |
| 75–83.7 s | 结尾 | 「你写字。Agent 排版。你点头。」手机收成图标，名字、一句话、仓库地址停 3.5 s |

画面里 Agent 的话、三张配图、改的样式、终端输出都是那一次真跑出来的（本机 Codex 0.167.2，App 里一次、终端里经 MCP 一次），所以重录一遍内容会不一样。快进的倍数按录制时每帧记下的时刻算。终端里只放了 Codex 说的话和它调的 MCP 工具名，每段话留前两行。

## 检查了什么

- `npx hyperframes check`：通过，没有错误。剩下的警告：6 处 `dead_stretch`（它只看页面元素，不看录屏里的变化；那几段录屏在动）、`font_face_local_only`（苹方、SF Mono 只在这台 Mac 上有，只在本机渲染）、`duplicate_media_discovery_risk`（两块面板用的是同一条录屏，有意的）、两类结构建议。
- 抽帧（`hyperframes snapshot` 约 90 帧、`framesheet.py` 12 帧、6 处转场各 12 帧连拍）：首帧有主体，最后一帧是片尾；说明都在画面下面那一条里，不压界面；飞进卡片的图落点和卡片里的图对得上。
- 声音：-17.0 LUFS，峰值 -7 dBTP；点击和卡片落进手机各有一声。**没试听过，请听一遍。**

## 没做的、要知道的

- 这次 Agent 写的卡片样式改动不大（标题变番茄红、底色变暖），不如前一次试录（奶油底加菜单边框）明显。要更明显得重录 `collab` 一段，约 12 分钟。
- 稿子没填标题和小红书正文，所以手机上卡片下面只有一行标题（取自正文第一个标题行）。
- 仓库地址在片尾，仓库现在还是私有的。
- 重出：`uv run tools/film.py <帧目录>`、`uv run tools/sound.py . 96`、`npx hyperframes@0.9.55 check`、`npx hyperframes@0.9.55 render -o renders/film.mp4 --video-frame-format png`，再用 ffmpeg 做 -17 LUFS 的配乐版和无声版。帧由 `DemoFramesTests` 的 `collab`、`agent` 两段录（`DEMO_AGENT_BIN` 指向 codex 所在的目录）。
