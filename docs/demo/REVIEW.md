# 主视频「你写，Agent 排」：交付说明（2026-11-16，第三版）

成片：`docs/screenshots/vibepost.mp4`（配乐）与 `docs/screenshots/vibepost-silent.mp4`（无声，不进 git），1920 × 1080、30 fps、H.264 yuv420p、faststart，56.5 秒，12.5 MB。README 顶上放的是传到 GitHub 的带声音的那一份（9.4 MB，crf 24；地址怎么来的见 `docs/release.md`），GitHub 的页面不播放仓库里的 mp4。封面：`docs/screenshots/vibepost-cover.png`（1920 × 1080）与 `vibepost-cover-3x4.png`（1242 × 1656）。分镜与规格见 `SPEC.md`。

## 第三版改了什么

看过第二版的人说节奏慢、Agent 干活的地方不显眼。

- 从 73.5 秒压到 56.5 秒。压掉的是停着不动的时间：开头从 10 秒（三句话、看一页字、亮名字）压到 6 秒，第 6 秒就开始打那句要求（原来是第 10 秒）；每一段的拍数重排（`tools/film.py` 的 `SEGMENTS`：每段占几拍），光标、弹簧、字的来去速度没变。
- 「Agent 动手」一段重排：卡片真变样的那几下各占一个拍点（换主题和分页、套组件、出配图），不再照真实时间的比例铺（那样变样挤在前 1.5 秒，后面 3.5 秒卡片不动）。每一下：那块面板的描边亮一下、镜头推近再回来、配乐上一个高音，下面一排「换主题、分页、套组件、生成配图」打一个勾。
- 写卡片样式、终端里的 Agent 两段：录屏里卡片变样的那一帧（比相邻两帧的图找出来的），面板描边同样亮一下。
- 去掉了「没排过版的样子」那个推近和翻页；「改了哪里」和「你点头」两句并成一句。

第二版（同一天）：整条片子快 1.25 倍；配图落下后在那一页停住；加了「自己动手调」；片尾只留图标、名字、仓库地址；配乐换成 `tools/groove_music.py`。

## 里面有什么

| 时间 | 镜头 | 内容 |
| --- | --- | --- |
| 0–3 s | 开头 | 「写完了。还要排版、配图、分页。」窗口里是一整屏没排过的字 |
| 3–6 s | 点题 | 窗口摆正；「Vibepost：你写字，Agent 排版。」光标点开 AI 助手，面板分成两块 |
| 6–9 s | 说一句 | 对话框里打出那句要求，发送 |
| 9–15 s | Agent 动手 | 左边的卡片变样（换主题、分页、套组件），右边出配图候选；每一下描边亮、打一个勾。快进 ×19 |
| 15–18 s | 你点头 | 编辑器里逐处标出的修改，光标点「全部接受」 |
| 18–24 s | 配图 | 三次：点一张候选图，图飞进那道菜的一页，停住 |
| 24–27 s | 之前 / 现在 | 光标在卡片上拖一条线，线左边是开头那张没排过的 |
| 27–31 s | 自己动手调 | 主题、图文尺寸、图片大小 |
| 31–36.5 s | 写卡片样式 | 让 Agent 给这篇写一套卡片样式（快进），再逐页翻过去 |
| 36.5–39.5 s | 写作手册 | 「存成我的写作手册」，确认框，保存 |
| 39.5–45.5 s | 终端 | 终端里的 Codex 经 MCP 新建一篇、分页、换主题（快进），翻三页 |
| 45.5–50.5 s | 发到 iPhone | 点「发送到 iPhone」，三张卡片飞进手机 |
| 50.5–56.5 s | 结尾 | 「你写字。Agent 排版。你点头。」手机收成图标，名字和仓库地址 |

画面里 Agent 的话、三张配图、改的样式、终端输出都是那一次真跑出来的（本机 Codex 0.167.2，App 里一次、终端里经 MCP 一次），所以重录一遍内容会不一样。快进的倍数按录制时每帧记下的时刻算。「Agent 动手」那一排四件事是照这一次录到的内容标的（第一次变样是换主题和插入分页，第二次是套「步骤」「提示」两个组件，第一张配图候选出来时算「生成配图」）；重录以后要对着帧再看一遍。终端里只放了 Codex 说的话和它调的 MCP 工具名，每段话留前两行。「自己动手调」那一段是另录的（`tune`，不用 AI）：稿子是 `collab` 那一段排好的原文，三张配图是那一段里 Agent 生成的原图，字号和图片高照那一段设的；分页是四页（那一段是三页），所以页眉上的页码不一样。

## 检查了什么

- `npx hyperframes check`：通过，没有错误，没有读不完的字。剩下的警告：`dead_stretch`（它只看页面元素，不看录屏里的变化；那几段录屏在动）、`font_face_local_only`（苹方、SF Mono 只在这台 Mac 上有，只在本机渲染）、`duplicate_media_discovery_risk`（两块面板用的是同一条录屏，有意的）、两类结构建议。
- 抽帧（`hyperframes snapshot` 三轮共 50 帧：每段开头、每次描边亮的那一下、配图停留、片尾）：首帧有主体，最后一帧是片尾；描边、推近、打勾都落在卡片变样的那一帧。
- 体积：渲染出来 25 MB，再压一遍到 12.5 MB（libx264 crf 21，和渲染结果比 PSNR 48.6 dB）。要做成动图时用 `uv run tools/webp.py renders/film.mp4 <输出>.webp`（960 × 540、一秒 12 帧，整条约 7.9 MB）。
- 声音：-16.8 LUFS，峰值 -5.1 dBTP。**配乐没试听过，请听一遍**（这一版拍点全挪了，开头三个音、结尾三个和弦、卡片变样时的高音都跟着新的时刻）。

## 没做的、要知道的

- Agent 写的卡片样式改动不大（标题变番茄红、底色变暖）。要更明显得重录 `collab` 一段，约 12 分钟。
- 稿子没填标题和小红书正文，所以手机上卡片下面只有一行标题（取自正文第一个标题行）。
- 配乐是现场合成的。想用真的曲库：`npx hyperframes auth login`（免费）之后可以从 HeyGen 的曲库里挑。
- 重出：`uv run tools/film.py <帧目录>`、`uv run tools/sound.py .`、`npx hyperframes@0.9.55 check`、`npx hyperframes@0.9.55 render -o renders/film.mp4 --video-frame-format png`，再用 ffmpeg 做 -17 LUFS 的配乐版（`-c:v libx264 -crf 21 -preset slow -af loudnorm=I=-17:TP=-2:LRA=11`）和无声版。帧由 `DemoFramesTests` 的 `collab`、`agent`、`tune` 三段录（前两段 `DEMO_AGENT_BIN` 指向 codex 所在的目录；`tune` 要先把那三张配图放到 `docs/demo/assets/brunch-1.png`–`brunch-3.png`）。
- 封面：`cover.html` 用无头 Chrome 截图，横版 `--window-size=1920,1080`，竖版地址后加 `#tall`、`--window-size=1242,1656`。
