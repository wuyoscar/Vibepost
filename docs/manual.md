# Vibepost 操作手册

Vibepost 把一篇 Markdown 排成小红书的图文卡片（也能排成公众号长文）。这份手册只讲 App 认得的写法与排版经验，跟用哪个模型无关；写什么内容、什么口味看写作手册。

- 每一行在卡片上另起一行，空行分段；放不下自动换到下一张。
- 下面的中文写法是规范写法，英文写法（`:::kicker`、`[[image:…]]`、`{{color:…|…}}`）也照样认，App 收下稿子时会换成中文。
- 代码块、行内代码里的记号只是文字。

## 块样式

一块就是空行隔开的一段（或一个组件）。在编辑器左上角「样式」、卡片上点选一块后的「换样式」里都能换；同一类里互换（段落类在段落类里，列表类在列表类里），列表也能拆回正文。

| 样式 | 写法 | 是什么 | 什么时候用 |
| --- | --- | --- | --- |
| 正文 | 直接写 | 普通的一段话 | 用在大多数内容 |
| 大标题 | `# 文字` | 这一页最大的字 | 用在一篇的主标题、一页的大字；一页里只放一个 |
| 小标题 | `## 文字` | 分段的标题 | 用在把一页分成几段 |
| 三级标题 | `### 文字` | 最小一级的标题 | 用在章节名、一条资讯的标题 |
| 引用 | `> 文字` | 别人说的话，左边一条竖线 | 用在原话、摘录 |
| 小标签 | `:::小标签` … `:::` | 标题上方或旁边的一行小字 | 用在来源、论文名、栏目名、日期；章节名用三级标题，不用小标签 |
| 提示 | `:::提示` … `:::` | 带底色的一块提示 | 用在结论、要点、注意事项 |
| 页尾 | `:::页尾` … `:::` | 这一页最底下的一行小字 | 用在出处、图片来源、免责声明：放在这一页的最后一块；写在页中间只会原地显示成小字、不贴底；论文名用小标签 |
| 等宽 | `:::等宽` … `:::` | 等宽字体的一块，空格与对齐照原样 | 用在 prompt、命令、需要对齐的文字 |
| 无序列表 | `- 一项` | 圆点开头的几项 | 用在并列的几点 |
| 有序列表 | `1. 第一项` | 带编号的几项 | 用在有先后、要数清楚的几点 |
| 标签列表 | `:::标签列表` … `:::` | 每项开头一个彩色胶囊标签（写成 [类别]） | 用在分类、对比、清单 |
| 步骤 | `:::步骤` … `:::` | 自动编号的步骤 | 用在操作步骤、流程 |

## 组件

单独一行 `:::名字` 开头、单独一行 `:::` 收尾，中间照常写 Markdown（可以嵌套）；没有收尾时按普通文字显示。
对齐写在名字后面：`:::提示 居中`、`:::提示 靠右`（靠左是默认，不用写）。认不出的名字不报错，渲染成 `class="mc-c c-名字"` 的容器，留给这篇的卡片样式。

### 小标签（kicker）

标题上方或旁边的一行小字。用在来源、论文名、栏目名、日期；章节名用三级标题，不用小标签。

```
:::小标签
论文：When Do Models Admit They Are Wrong?
:::
```

### 提示（note）

带底色的一块提示。用在结论、要点、注意事项。

```
:::提示
所有问题放在同一个请求里并行发出。
:::
```

### 页尾（footnote）

这一页最底下的一行小字。用在出处、图片来源、免责声明：放在这一页的最后一块；写在页中间只会原地显示成小字、不贴底；论文名用小标签。

```
:::页尾
图片来源：作者自摄
:::
```

### 等宽（mono）

等宽字体的一块，空格与对齐照原样。用在 prompt、命令、需要对齐的文字。

```
:::等宽
You are a helpful assistant.
:::
```

### 标签列表（rows）

每项开头一个彩色胶囊标签（写成 [类别]）。用在分类、对比、清单。

```
:::标签列表
- [保留] 一句话说清楚要做什么
- [删掉] 「只输出 JSON」这类格式指令
:::
```

### 步骤（steps）

自动编号的步骤。用在操作步骤、流程。

```
:::步骤
- 先把问题拆开
- 每一块单独问
- 最后合起来
:::
```

## 记号

- 图片 `[[图片:编号]]`：一张图或一段实况，独占一行；编号由 App 生成：插图、拖进图片时自动写，不用手写。
- 拼图 `[[图片:甲|乙]]`、`[[图片:甲|乙|4x3]]`：两张图并排，独占一行；比例 1x1、4x3、3x2、16x9（不写就是 16x9）。
- 分页 `[[分页]]`：独占一行，后面的内容从下一张卡片开始；也可以按 ⌘↩。
- 结尾页 `[[结尾]]`：独占一行，后面的内容排成结尾页（居中、留白，最后是署名）；关注引导、下期预告写在它后面。
- 字色 `{{字色:#d9480f|文字}}`：给几个字换颜色；选中文字用浮动条点一下最省事。
- 高亮 `{{高亮:#fff3bf|文字}}`：给几个字加底色。
- 下划线 `{{下划线:实线|文字}}`、`{{下划线:虚线|文字}}`：实线或虚线的下划线。
- 标注 `{{标注:类别|文字}}`：按类别上色；同一个类别在一篇里颜色固定，标签列表里同名的 [类别] 也是这个颜色。

- 记号要照原样保留：改稿时不要改写、翻译、挪动或删掉它们（换样式、挪图片用 App 的工具）。
- 冒号、竖线两侧不加空格；色值是 `#` 加 3–8 位十六进制数。

## 行内格式

`**加粗**` 加粗、`*斜体*` 斜体、`~~删除线~~` 删除线、`` `代码` `` 行内代码、`[文字](https://…)` 链接；标题 `#`、引用 `>`、列表 `-` / `1.`、表格、分割线 `---` 照常写。

## 排版经验

- 来源、论文名这类挂在标题旁边的小字用小标签，不用页尾。
- 页尾只放在一页的最后一块（出处、免责声明）；写在中间不贴底，只是原地的一行小字。
- 章节名用三级标题。标题会带着后面第一段一起换页，不要让一页只剩一个章节名。
- 一张卡片 180–280 字最好读，超过 300 字偏挤。一条一页（每条后面写 [[分页]]）时，溢出就收紧文字或拆成两页，太空就和上一条并成一页。
- 颜色少而有用：同一类的词用同一个标注，关键的一句放提示框；不要整段上色。
- 排完版看一遍每页的问题（只有标题、太空、溢出），逐页处理好再交差。
