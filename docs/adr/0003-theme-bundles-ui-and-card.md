# 0003：主题同时决定界面皮肤、卡片结构与卡片配色

- 状态：已采纳（2026-09-28）；「主题同时决定界面皮肤」一条已被 [ADR 0007](0007-themes-style-cards-only.md) 取代（2026-09-30），其余照旧

## 决定
- 「主题」是一个选择，同时切换编辑器界面皮肤、卡片结构（`CARD_TEMPLATES` 条目）和卡片配色，并带一组默认字体。
- 每篇稿子记住自己的主题；新稿沿用上一次选的主题；三个取色器是单篇微调，换主题时重置。
  - 2026-09-29 补充：卡片配色扩成五个角色（背景、文字、强调、辅助、衬底），检查器的「配色」有五个色块、配色库与色轮，仍然只改这一篇、换主题时重置；界面皮肤不随配色变。主题的辅助色与衬底取三色规则推出的值（见 app-api.md 的 palettes）。
- 内部仍分三层（皮肤 / 结构 / 配色）：新结构以覆盖项深度合并到基础结构上（原为 `classic`；新排版引擎起是 `src/engine/structures.js` 里不对外的 `BASE`，8 种结构都在它上面合并），新增一个主题 = 一条注册表记录 + 一块皮肤令牌 +（可选）一个结构。
- 首批 8 个：浅色 5 个（白、灰、纸、雾、苔，参考 IBM Carbon），风格 3 个（暗夜、赛博 OscarMax、废土）。风格只体现在标签、细线、字体等边角，正文区保持干净。
