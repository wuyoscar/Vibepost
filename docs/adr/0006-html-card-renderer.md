# 0006：卡片改用 HTML/CSS 排版，像 PPT 一样可以直接编排

- 状态：已采纳（2026-09-29）

## 背景
卡片由手写的 Canvas 引擎排版与绘制（`src/engine/layout.js`、`paint.js`）：每多一种版式元素就要手写一段排版与绘制，做不出精细的设计（小标签、胶囊标签列表、代码里的语义标注、混排大标题、图文混排），图片也只能整块放。作者要的是「足够的自由空间」，同时「每个人都觉得好用」，并且「像 PPT：人在卡片上直接编排，Agent 用人能用的同一套编排去操作」。

## 决定
- **排版交给 WebKit**：每页卡片是一段 HTML，放在 Shadow DOM 里，套卡片样式（`src/cards/card.css`）+ 主题样式（`src/cards/themes/`）+ 这一篇的自定义样式。逻辑尺寸仍是 864 × 1152。
- **舞台是可操作的真实 DOM**：预览直接显示卡片的 DOM（按比例缩小），元素可以点选、拖动、换样式；打字时不出图。
- **导出由原生壳截图**：同一份 HTML 与样式交给壳里不上屏的 WKWebView（`CardRasterizer.swift`，宿主页 `src/cards/raster-host.html`），`takeSnapshot` 后统一成 sRGB、重采样到 1728 × 2304。实测同一页多次出图逐字节相同，每页约 85 ms（第一页含启动约 200 ms）。浏览器开发模式没有壳，退回 html2canvas。
- **Markdown 仍是唯一的底层格式**：组件用容器写法 `:::名字 属性` … `:::`，行内标注 `{{mark:类别|文字}}`，页面版式与自由元素的位置都是属性。人在卡片上的每个操作、编辑器里的每次修改、Agent 的每个工具调用，最后都是对这份文本的一次可撤销的编辑。
- **自由度分层，默认路径不碰代码**：内置组件与版式（`/` 菜单、插入菜单、卡片上直接点选）→ 让 AI 按描述生成这一篇的组件与样式（走修改对比，可存成自己的组件库）→「高级」里的自定义样式与自由摆放。
- **分页在页面里量**：在一个与卡片同尺寸的隐藏容器里逐块放入测量；段落按行、列表按项、表格按行（重复表头）拆开，标题跟着下一块。
- **Canvas 引擎退役**（与 v3 相同的绞杀式替换）：新引擎先交出与旧引擎相同的接口（每页的像素与排版摘要），试用一段后删掉旧引擎。

## 进展（2026-09-29）
- 已接进出图流水线，开了封面的稿子也走 HTML 卡片。舞台放活的卡片元素；导出、发送、缩略图、看一页经 `render.canvases()` 等出图，出图按整页 HTML 缓存。
- 8 种卡片结构的版心、标题比例、底板从 `src/engine/structures.js` 读成每页的 CSS 变量（`src/cards/cards.js`），页面框架在 `chrome.js` / `structures.css`；配色角色与对比度保护在 `src/engine/colors.js`，图片的共用规则在 `src/engine/media.js`。
- 页面结果（`src/cards/summary.js`）与原来的 Canvas 引擎同形状：逐行文字对得上原文、图片点选框、逐行落点、字数与填满；分页含标题跟着走、一页一段实况、结尾页与署名、末页回填。
- 封面（`src/cards/cover.js`）按各结构的 cover 规格：标题在量尺卡里取放得下的最大字号、放不下截断；底图固定框 / 跟在文字下 / 铺满加渐变遮罩（实况只到遮罩最不透处）；各结构的封面装饰与页眉页脚。
- 卡片上的直接编排（`src/stage/blocks.js` + 纯函数 `src/cards/blocks.js`）：点选一块出工具条（上移、下移、换样式、让 AI 改、删除），拖动换位置；AI 与外部 Agent 用同一套（工具 `restyle_block`）。行首 `/` 菜单能插组件。批注几处一次交给 AI（`src/stage/annotations.js`）；AI 助手的设计方向（更醒目、更安静……）；这一篇的卡片样式（`cardCss`，工具 `set_card_css`）。
- 2026-09-29 起 HTML 卡片是唯一的引擎：Canvas 引擎（`src/engine/text.js`、`paginate.js`、`layout.js`、`cover.js`、`paint.js`）与「版式 › 排版」的切换已删，像素基准按 HTML 卡片重录。
- 还没做：自己的组件库、自由摆放的元素。

## 后果
- 精细度与自由度由 CSS 决定，新组件、新版式主要是写样式，AI 也能生成。
- 舞台预览与导出同源，所见即所得；导出比 Canvas 慢（每页约 85 ms），只在导出、发送、实况时发生。
- 像素基准要按新渲染重录；与字体、WebKit 版本相关的像素细节以壳里的截图为准。
- 卡片样式与自定义样式关在 Shadow DOM 里，不影响 App 界面；自定义样式要过滤（不许脚本、外部地址、`@import`），受 CSP 约束。
