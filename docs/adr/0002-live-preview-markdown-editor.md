# 0002：编辑器用实时预览，Markdown 是唯一的底层格式

- 状态：已采纳（2026-09-29）

## 背景
编辑框显示原始 Markdown（`#`、`>`、`[[分页]]`、`{{color:…}}`）对写作的人很乱；但 AI 要能直接读写稿子，导出和测试也依赖稳定的文本格式。

## 决定
- 编辑器改为「实时预览」（Typora / Obsidian Live Preview 式）：标题、引用、列表、加粗等直接显示为排好的样子；图片显示为缩略图卡片，分页显示为细虚线；光标所在行才露出 Markdown 标记。
- 提供「源码」开关（⌘/）显示纯 Markdown。
- 底层存储始终是 Markdown 文本，显示层只做装饰（decoration），不改写文本，保证自定义语法一字不差地往返。
- 实现选用 CodeMirror 6（MIT）：它的装饰与小部件机制正适合「显示富文本、存储纯文本」。

## 取舍
不选 ProseMirror / Tiptap 这类所见即所得编辑器：它们以富文本树为准，再序列化成 Markdown，自定义语法容易在转换中丢失或被改写，AI 往返不稳。
