# 0005：许可证用 CC BY-NC-SA 4.0

- 状态：已采纳（2026-09-29）

## 背景
公开源码之前要给 MediaCraft 选一个许可证。作者要三件事：别人用要署名；不许拿去商用；改了再发布必须用同样的条款公开，不能拿去做闭源产品。许可证文本本身也受版权保护，所以用现成的标准许可证，不自己拟一份。

## 决定
- MediaCraft 自己的代码、文档与素材用 Creative Commons 署名—非商业性使用—相同方式共享 4.0 国际（CC BY-NC-SA 4.0）。`LICENSE` 放官方英文法律文本原文（https://creativecommons.org/licenses/by-nc-sa/4.0/legalcode.txt），不改一个字；中文译本见官网。
- 第三方组件（CodeMirror、JSZip、html2canvas 等 MIT 库，按 OFL 打包的字体）保留各自的许可证，清单在 README。

## 后果
- 这不是 OSI 定义的开源许可证，而是「源码公开」：GitHub 显示为其他许可证，一些只收开源软件的渠道不能收录。
- 作者是版权人，不受「非商业」限制，以后自己商用或改许可证都可以；别人贡献的代码按同一许可证进来，改许可证时要考虑这一点。
- CC 许可证不是为软件写的（没有专利条款，也没有「分发二进制要附源码」的软件式措辞）；这是为了用现成、各国通用的标准文本，而不是自拟一份没经过律师审查的许可证。
