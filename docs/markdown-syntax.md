# MediaCraft 的 Markdown 写法

稿子就是一段 Markdown 文本。这里写清楚 MediaCraft 认哪些写法、边界情况怎么处理。规则由解析器 `src/engine/markdown.js` 实现，页面里可以用 `mediacraft.engine.parse(markdown)` 看到解析结果（见 [app-api.md](app-api.md#engine解析器)）。

## 总体规则

- **按行排版。** 正文里的每一行在卡片上都另起一行，不需要行尾两个空格；列表项只占一行。
- **空行分段，多空几行就多留些空白**，可以用来控制卡片的节奏。只有空格、制表符的行也算空行；卡片顶上的空行不留白。
- **行首行尾的空白不显示**（半角、全角空格和制表符都一样）。行首缩进不会把文字变成代码块，也不会让列表嵌套。
- **行内格式不跨行**：加粗、颜色、链接等的开头和结尾要在同一行里，否则按原文显示。编辑时光标所在的那一行露出标记，也只牵连这一行。
- **标记要成对**：没有配上的 `**`、`~~`、`` ` ``、`{{…|` 都按原文显示，不会吞掉后面的字。
- 不支持反斜杠转义和 HTML：`\*`、`<b>`、`&amp;` 都原样显示。
- 下划线不是强调：`_斜体_`、`__加粗__` 原样显示，请用星号。
- 不支持微信式表情代码：`[微笑]`、`[捂脸]` 原样显示为文字，表情请直接输入 Emoji。从微信复制来的这类文字粘贴进编辑器时会自动换成 Emoji。

## 标题

| 写法 | 效果 |
| --- | --- |
| `# 标题` | 一级标题 |
| `## 标题` | 二级标题 |
| `### 标题` | 三级标题 |
| `####` 到 `######` | 按三级标题画 |

- 井号后面要有空格（或制表符），再跟文字。`#标题`、单独的 `#`、`# `、七个井号都是普通文字。
- 行尾的井号原样保留：`# 标题 #` 显示「标题 #」。
- 行首可以有缩进：`   # 标题` 也是标题。
- 不支持在下一行写 `===` 或 `---` 的标题写法（`---` 是分割线）。
- 标题放不下后面第一段时和它一起换到下一张卡片，不会孤零零留在页底。
- 稿子设置里开了「首页做封面」时，封面的大标题取标题框（不是正文里的 `#`），见下面的[封面](#封面首页做封面)。

## 段落

- 相邻的几行是一个段落，每行各自起一行；空行隔开的是另一段。
- 行尾两个空格、行尾反斜杠没有特别含义（反斜杠照常显示）。

## 列表

| 写法 | 效果 |
| --- | --- |
| `- 项目`、`* 项目`、`+ 项目` | 无序列表，画圆点 |
| `1. 项目`、`2) 项目` | 有序列表，**编号照原样显示**（`7.`、`001.`、`2024.` 都不改） |

- 标记后要有空格（或制表符）再跟文字：`-无空格`、`1.无空格`、`3、三` 是普通文字；只有 `- `、`1.` 没有文字时也是普通文字。
- 每项只占一行。下一行没有列表标记就是普通段落。
- 缩进不产生嵌套：`  - 子项` 与上一层对齐。
- 紧挨着的列表项（有序、无序可以混着写）是同一个列表，编号区宽度一致；编号比悬挂区宽（如 `2024.`）时整组一起右移。
- 不支持任务列表：`- [ ] 待办` 显示「[ ] 待办」。
- `* *斜*` 是列表项，内容是斜体「斜」；`- - -` 是分割线，不是列表。

## 引用

- 以 `> ` 开头（大于号后要有空格）。连续的引用行是一段引用，左侧一条连续的竖线；空行隔开就是两段、两条竖线。
- 单独一个 `>` 是引用里的空行，前后仍是同一段引用。
- 引用里不再解析标题、列表和嵌套引用：`> # 文字` 显示「# 文字」，`> > 文字` 显示「> 文字」。行内格式照常可用。
- `>文字`（没有空格）、`>` 后跟制表符、全角 `＞` 都不是引用。
- 引用跨页时每张卡片上各画一段竖线。

## 分割线

- 一行只有三个或更多相同的 `-`、`*` 或 `_`，中间可以夹空格：`---`、`***`、`___`、`- - -`、`* * *`、`----------`、`-- -`。
- 两个不算（`--`；`* *` 是内容为「*」的列表项），混用不算（`-*-`），中文破折号 `——` 不算。
- 分割线落在一张卡片最顶上时不画（上面没有东西可分隔）。

## 行内格式

| 写法 | 效果 |
| --- | --- |
| `**加粗**` | 加粗 |
| `*斜体*` | 斜体 |
| `***加粗斜体***` | 加粗 + 斜体 |
| `~~删除线~~` | 删除线 |
| `` `代码` `` | 行内代码：代码字体、浅色底块 |
| `{{color:#d9480f\|文字}}` | 文字颜色 |
| `{{bg:#fff3bf\|文字}}` | 高亮底色 |
| `{{underline:solid\|文字}}` | 实线下划线 |
| `{{underline:dashed\|文字}}` | 虚线下划线 |
| `[文字](https://…)` | 链接 |

### 加粗与斜体

- 可以互相嵌套：`**粗*斜*粗**`、`*斜**粗**斜*`、`***粗斜** 斜*`。
- 标记里侧可以有空格：`** 文字 **` 也会加粗；词中间也行：`中**文**字`。
- 必须成对：`5 * 3 = 15`、`**没写完` 原样显示。交叉时先收尾的一对生效，夹在里面没配上的按原文显示：`**a*b**c*` 显示加粗的「a*b」和原样的「c*」。
- 连续四个及以上的星号原样显示。

### 删除线

- 恰好两个波浪号。开头的 `~~` 后面、结尾的 `~~` 前面都要紧贴文字：`~~删掉~~` 有删除线，`好开心~~ 明天见~~` 原样显示。
- `~` 单个、`~~~` 三个及以上都原样显示。删除线不嵌套：开着的时候，下一个能收尾的 `~~` 就收尾。

### 行内代码

- 用反引号包住；里面的内容原样显示，不再解析任何格式（`` `**不粗**` ``）。
- 内容里有反引号时，用两个（或更多）反引号包住：``` ``a`b`` ```。内容两端的空格保留。
- 没有配对的反引号原样显示。
- 代码比一整行还长时按字折行。

### 颜色、高亮与下划线

- `{{color:#色值|文字}}`、`{{bg:#色值|文字}}`：色值是 `#` 加 3 到 8 位十六进制数（`#abc`、`#d9480f`、`#d9480f80`），大小写都行。
- `{{underline:solid|文字}}` 实线、`{{underline:dashed|文字}}` 虚线；其他样式（如 `wavy`）原样显示。
- `color`、`bg`、`underline` 要小写，冒号、竖线两侧不能加空格；颜色名（`red`）、位数不对的色值都原样显示。
- 文字里可以再用加粗、斜体、删除线、行内代码、链接，也可以再套一层颜色（里层优先）；加粗也可以包住整个颜色标记。
- 文字里可以有 `|`；遇到第一个配对的 `}}` 结束。文字为空（`{{color:#abc|}}`）时整个标记什么都不显示。

### 链接

- `[文字](网址)`，网址后可以带标题：`[文字](网址 "标题")`（标题不显示）。
- 只有 `http://`、`https://`、`mailto:` 开头的才是链接（不分大小写）；其他网址（`www.…`、相对路径）只显示文字，不当链接。
- 网址里不能有空白和方括号，圆括号要成对（`https://x.com/(p)` 可以）。
- 链接文字不能为空、不能再有方括号；`[文字]` 后面没有紧跟 `(…)` 时原样显示。
- 不自动识别裸网址和 `<https://…>`。

## 表格

```
| 项目 | 说明 |
| :--- | ---: |
| 字号 | **34** |
```

- 第一行是表头，第二行是分隔行，后面紧跟的是表格行。每行用 `|` 分格，行首行尾的 `|` 可以省略；表格可以直接写在文字下一行。
- 至少两列：只有一列的写法不是表格。
- 分隔行每格至少三个 `-`，可加冒号表示对齐：`:---` 左、`---:` 右、`:---:` 居中。`--`、`|---` 这样的分隔行不算，整段按普通文字显示。
- 表格行是至少有两格的行。遇到空行、只有一格的行、`[[分页]]`、`[[结尾]]`、整行的拼图标记，或任何没有 `|` 的行，表格就结束。
- 列数取各行里最多的那一行，缺的格子留空。只有表头、没有内容行也可以。
- 格子里可以用行内格式。`|` 总是分格：行内代码里的 `|` 也会分格，也不支持 `\|` 转义。格子里的 `[[image:…]]` 不显示。
- 表格放不下时按行拆到后面的卡片，每张卡片重复表头。

## 图片

### 应用内图片：`[[image:图片编号]]`

- 插入、拖入图片时自动写进稿子，编号由应用生成（英文字母、数字、`_`、`-`）；编号里有空格、中文或其他符号时原样显示为文字。
- 通常单独占一行（两侧可以有空格）。写在一行文字中间时，图片把这一行拆开：前面的文字、图片、后面的文字依次排下来。
- 列表项里的图片同样拆开，图片后面的文字变成普通段落；标题、引用里的图片也单独显示，引用在图片后面继续。
- 实况（Live Photo）用同样的写法，编号指向一段实况时卡片上就是实况；一张卡片最多放一段实况，第二段自动换到下一张。
- 编号找不到对应的图时不显示。
- 行内代码里的 `[[image:…]]` 只是文字。

### 拼图：`[[image:图甲|图乙]]`、`[[image:图甲|图乙|比例]]`

- 两张图并排成一组，必须单独占一行；写在文字中间时原样显示。
- 比例是整组的宽高比，支持 `1x1`、`4x3`、`3x2`、`16x9`（不写时就是 16x9）；写别的数值按 16x9。`4:3`、`1x1` 两侧带空格这类写法不是拼图，原样显示。
- 两张里缺一张时显示成单张图。

### 标准 Markdown 图片：`![说明](文件名)`

- 单独占一行时，按文件名找回已经插进稿子的同名图片：只看最后的文件名（`dir/a.png`、`https://…/a.png` 都找 `a.png`），不分大小写。可以带标题：`![说明](a.png "标题")`。
- 找不到同名图片时不显示。
- 与文字写在同一行时不当图片：`![图](a.png) 文字` 显示「!图 文字」。

## 分页：`[[分页]]`

- 单独占一行（两侧可以有空格）时，后面的内容从新的一张卡片开始，标记本身不画；作者手动分页优先，标题也可以单独成一张。
- 连着写几个，或写在稿子末尾，不会产生空白卡片。
- 写在文字中间、列表项里，或写成 `[[ 分页 ]]`、`［［分页］］` 时原样显示。

### 自动分页的规矩

- 放不下就换到下一张；标题连同后面第一段一起走，分割线落在一张的最顶上时不画。
- **末张太短时回填**：最后一张用了不到四分之一、又不是 `[[分页]]` 换出来的，就从前一张挪几块下来，让两张都不太空。优先整块挪（不把标题、分割线留在前一张的页底）；整块挪不成时，从原文里另起的一行、列表的一项，或上一行以句号问号叹号结尾的地方断开，不从一句话的中间断。挪完页数不变，前一张也至少留四分之一；怎么挪都到不了四分之一时，挑让最后一张最满的挪法。
- 预览下面的胶片上，每张正文卡的右下角写着字数（和小红书一样，空白不计），底边一条细线是这张填满了多少：有好几张时不到四分之一（偏空）是黄色，超过 300 字（偏挤）是红色，悬停时写着原因和建议。一张 180–280 字读起来最舒服。

## 结尾页：`[[结尾]]`

```
正文最后一段。

[[结尾]]

## 下期预告
关注我，下期讲怎么用 AI 写综述。
**第 3 期**
```

- 单独占一行（两侧可以有空格）时，后面的内容排成结尾页：段落与标题居中、两侧比正文多留白，整页上下居中，最后是署名（大头像、名字，填了账号时还有账号），上面一小段强调色短线隔开。样式随主题（页眉、页码照常；撞色的结尾页和封面一样是满版的强调色……）。
- 结尾页里的写法和正文一样（列表、引用、图片都能用）；写多了放不下时接着排到下一张，每张都上下居中，署名在最后一张。
- `[[结尾]]` 后面什么都不写，就是一张只有署名的结尾页。关注、收藏的引导语、下期预告、「第 N 期」这类合集编号都写在它后面。
- 只认第一个 `[[结尾]]`：后面再写的不画，也不另起结尾页。
- 和 `[[分页]]` 一样：写在文字中间、列表项里，或写成 `[[ 结尾 ]]`、`［［结尾］］` 时原样显示；不进「复制全文」的纯文本，长文里没有结尾页（后面的内容照常接在正文后面）。
- 「插入」菜单的「结尾页」与「/」菜单（`jw`、`end`）插入的就是它。

## 封面（首页做封面）

封面不是一种写法，是稿子的一项设置（检查器「封面」，App API 的 `cover`，见 [app-api.md](app-api.md#drafts稿子)）：

- 默认关，旧稿子不变。开了之后第 1 张是封面，正文从第 2 张开始，正文页都按内页排（首页页眉的署名挪到了封面上）。
- **标题**取标题框；标题框空着时取正文第一行字（和稿件列表里的名字一样）。正文里的 `# 标题` 照样留在正文里。
- 标题按实测宽度自动定字号：在这个主题封面的上下限之间取放得下的最大字号，最多三行（大标题的主题四行），英文单词不拆开，换行尽量落在词与词之间；最小字号也放不下时，最后一行末尾截断加「…」。
- **副标题**另填一行（最多 60 字，可不填），不取正文第一段：第一段本来就在第 2 张上，拿来当副标题会重复。
- **底图**可选：这篇的一张图或实况，或另传一张只给封面用的图（进这篇的图片，不插进正文）。图放进主题给的框里：多数主题图在上、标题与副标题在下，备忘是标题在上、图在下；手帐是带白边、微微倾斜的照片，撞色的图压在满版强调色上。实况也一样，发送、导出时封面就是一张实况。
- 8 个主题各有自己的封面：备忘是黄色小签下的粗黑大标题与一条细线，纯白、纯黑是页眉一条线加粗大标题，手帐是文楷大标题与薄荷色的马克笔底，柔光是居中的标题压在淡紫渐变上，陶土是衬线大标题上一个珊瑚色圆点，杂志是居中刊头、居中衬线标题与短线，撞色是满版柠檬黄与得意黑大标题。

## 代码块

````
```js
const answer = 42;
```
````

- 以三个（或更多）反引号开头的一行起，到反引号数不少于开头的一行止；开头那行可以写语言名。里面的内容原样保留，不解析任何格式。
- 没有收尾的 ```` ``` ```` 按普通文字显示，免得打字途中把后文都变成代码。
- `~~~` 围起来的、缩进四格的都不是代码块。
- 卡片上画成一块浅底圆角框，用代码字体逐行照原文显示（行首缩进保留），比一行还长的行折到下一行；跨页时每张卡片上各有一个框。

## 组件（HTML 卡片）：`:::名字` … `:::`

卡片（ADR 0006）认得几种组件，把一段或一组内容排成别的样子。

````
:::kicker
核心动作：拆
:::

:::rows
- [choice] `team` billing / shipping / account，再加一个 other 兜底
- [drop] `Output JSON only` 格式指令没用了
:::

:::note align=center
所有问题放在同一个请求里并行发出。
:::
````

- 单独一行 `:::名字`（后面可以写属性）开头，单独一行 `:::` 收尾；中间照常写 Markdown，可以嵌套。没有收尾时按普通文字显示。
- 内置组件（中英文名都认）：`kicker` 小标签、`note` 提示、`footnote` 页尾（贴在正文区底部）、`mono` 等宽、`rows` 标签列表（每项开头的 `[类别]` 是胶囊标签，颜色与同名的标注一样）、`steps` 步骤（自动编号）。
- 属性：`align=center`（或 `right`）对齐。认不出的名字也不报错：渲染成 `class="mc-c c-名字"` 的容器，留给自定义样式。
- 行内标注 `{{mark:类别|文字}}`：同一个类别在一篇里颜色固定（按第一次出现的先后取四种之一），适合在代码或 prompt 里标出「这一段是哪一类」。
- 不用手写：在预览里点选一块，工具条上「换样式」就能在正文、小标签、提示、页尾、等宽之间切换（列表在列表、标签列表、步骤之间），也能对齐、改标题级别；拖动一块换位置，上移 / 下移、删除，都能 ⌘Z。AI 助手与外部 Agent 用同一套操作（工具 `restyle_block`、`move_section`）。工具条上「批注」可以在几块旁边各写一句想怎么改，卡片上出编号圆点，右上角「交给 AI」一次发给 AI 助手（批注不进原文、不存盘）。

## 与原来卡片的差异

新解析器按上面的规则解析。以下几处与原来的卡片不同，是有意的改动（测试见 `MarkdownParserTests.intentionalDifferences`）：

| 写法 | 原来的卡片 | 现在 | 原因 |
| --- | --- | --- | --- |
| 落单的 `**`（如 `a ** b`、跨行的 `**粗⏎继续**`） | `**` 被删掉，也不加粗 | 原样显示 | 与落单的 `*`、`~~`、`` ` `` 一致；删掉会让人看不出少写了一半 |
| `*斜**粗**斜*` | 只有斜体，加粗丢了 | 斜体里嵌加粗 | 嵌套本来就支持（`**粗*斜*粗**`），两个方向应一致 |
| 单独一行 `>` | 画成文字「>」，把引用断成两段 | 引用里的空行 | 通用 Markdown 的写法，用来在一段引用里分段 |
| ```` ``` ```` 代码块 | 每行当普通文字，反引号露出来 | 代码块 | 长文模式本来就支持；卡片的画法随新排版引擎 |
| 标题、引用里的 `[[image:…]]` | 图片连同标记一起消失 | 图片单独显示 | 不静默丢掉作者放进去的图 |
| 紧跟在表格下一行的拼图 | 被当成一行表格，格子里是半截标记 | 表格结束，拼图照常显示 | 拖图片到表格后面时就会写成这样 |

长文模式（公众号）也用这棵语法树排版，写法规则与卡片一致：有序列表的编号照原文显示，行内格式同样不跨行，`[[分页]]`、`[[结尾]]` 在长文里不起作用，封面也只在图文卡片里有。
