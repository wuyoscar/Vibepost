# 英文简明表达

适合英文教程、工具介绍、技术解释和产品说明。选中这份不会自动把中文稿翻成英文；只有用户要求英文写作或翻译时才改变语言。不宣称符合某项受控语言标准。

## 写法

- 用读者熟悉的词、明确的主体和直接动词。能说明谁做什么时，优先用主动句。
- 同一个概念保持同一个术语，不为了避免重复轮流换名称。必要的专业词保留，第一次出现时用简短解释帮助读者。
- 一条步骤说清一个动作。条件先于动作，例如 “If the file exists, open it.”；不要让用户做完才发现前提不成立。
- 句子过长、嵌套过深时拆开，保持完整语法和逻辑连接，不把说明削成缺少主语或冠词的电报句。
- 删除没有信息的宣传形容词；用原材料中已有的功能、条件和结果解释价值，不编造性能或体验。

## 保真

may、might、could、should 等词可能表达真实的不确定性或建议，不能一律改成 will 或 must。保留否定、条件、数量、比较范围与作者已有的拼写习惯。

代码、命令、标识符、路径、URL、原始报错、版本、数字与单位保持原样。翻译时保留引用和 Markdown 结构；Vibepost 的图片、分页、颜色与组件标记不能翻译或删除。

## 输出

只审阅时说明具体问题与替换建议；要求改稿时修改指定文件或选区，进入 App 审阅。交付前读一遍，确认读者能看清对象、动作、条件和结果，不额外附长篇规则清单。
