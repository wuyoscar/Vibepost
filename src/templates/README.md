# 自带模板

每个 `.md` 是一套模板：开头 `---` 之间是 front matter（与写作手册同一套解析：一行一个 `键: 值`，`|` 后面缩进的几行是多行的值），后面是卡片内容（Markdown，只用中文记号）。键：`name` 模板名（与文件名一致）、`description` 一句话说明、`tags` 逗号分隔的两个标签（题材一个、风格一个：简洁 / 柔和 / 有态度）、`theme` 主题 id（见 `src/themes/themes.js`）、`colors` 可选（缩进的几行 `bg: #…`、`text: #…`、`accent: #…`，缺的按主题）、`fontSize` / `lineHeight` / `imageMaxHeight` 可选（字号 24–40、行距 1–2.4、图片最大高 220–1048；自带模板统一 30 / 1.6，字能多放三成）、`cover` 可选（缩进的几行 `enabled: true`、`subtitle: 一行副标题`、`image: 图片编号`）、`images` 可选（缩进的几行 `编号: 相对网页根的路径`，图片复用 `docs/guide-assets/`，新图放 `docs/template-assets/`）、`caption` 小红书正文（`|` 多行，最后一行 3–5 个 #话题）。正文第一块是 `# 标题`（封面与稿件标题都从它取），每张卡片之间单独一行 `[[分页]]`，关注引导写在 `[[结尾]]` 后面；字为主、图为辅：自带模板统一 `fontSize: 30`、`lineHeight: 1.6`，正文卡片把字写满——每张 250–300 字（标题、列表、提示框的字都算；超过 300 字排版自检报「偏挤」，字多到放不下会被拆到下一页），一套模板正文里至多一张整幅图 `[[图片:编号]]`，放在那张卡片的文字后面（那张约 190–220 字，图按剩下的空间缩小；字再多图就被挤到下一页）。TemplatesTests 会查每套的正文页数正好等于分页数 + 1、没有太空或偏挤的页。改完跑 `node scripts/build-templates.mjs` 重新生成登记表 `index.js`（TemplatesTests 会比对登记表、记号写法，并把每套都建成稿子出图查排版）。
