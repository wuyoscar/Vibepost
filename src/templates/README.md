# 自带模板

每个 `.md` 是一套模板：开头 `---` 之间是 front matter（与写作手册同一套解析：一行一个 `键: 值`，`|` 后面缩进的几行是多行的值），后面是卡片内容（Markdown，只用中文记号）。键：`name` 模板名（与文件名一致）、`description` 一句话说明、`tags` 逗号分隔的两个标签（题材一个、风格一个：简洁 / 柔和 / 有态度）、`theme` 主题 id（见 `src/themes/themes.js`）、`colors` 可选（缩进的几行 `bg: #…`、`text: #…`、`accent: #…`，缺的按主题）、`cover` 可选（缩进的几行 `enabled: true`、`subtitle: 一行副标题`、`image: 图片编号`）、`images` 可选（缩进的几行 `编号: 相对网页根的路径`，图片复用 `docs/guide-assets/`，新图放 `docs/template-assets/`）、`caption` 小红书正文（`|` 多行，最后一行 3–5 个 #话题）。正文第一块是 `# 标题`（封面与稿件标题都从它取），每张卡片之间单独一行 `[[分页]]`，关注引导写在 `[[结尾]]` 后面；字为主、图为辅：正文卡片把字写满（标题加几段 190–250 字，带标签列表 / 步骤 / 表格的 140–190 字，字多了会被拆到下一页），一套模板正文里至多一张整幅图 `[[图片:编号]]`，放在那张卡片的文字后面（约 100–130 字，图按剩下的空间缩小；字再多图就被挤到下一页）。改完跑 `node scripts/build-templates.mjs` 重新生成登记表 `index.js`（TemplatesTests 会比对登记表、记号写法，并把每套都建成稿子出图查排版）。
