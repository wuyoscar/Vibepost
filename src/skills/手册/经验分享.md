# 经验分享

给正要做同一件事的人写。他想知道的是你当时的情况、你怎么做的、哪一步出了岔子，不是一份通用的建议。怎么写的底线照内置的写作技能，这份只补这类稿子的取材和结构。

## 先问清楚

- 这件事是什么时候做的、花了多久、花了多少钱（读者要拿来和自己比）。
- 最麻烦的是哪一步，有没有做错、重来的地方。
- 作者的情况和大多数读者有什么不一样（一个人搬还是一家人搬，零基础还是学过）。不一样的地方要写明，读者才知道哪些能照搬。
- 有没有当时的截图、照片、清单、账单。

## 结构（5–8 张）

1. 封面：一句具体的话，带上最能说明情况的一个条件。「一个人搬家，第一周要办的 12 件事」比「搬家经验分享」好。
2. 我的情况：一两句交代清楚背景，读者据此判断这篇适不适合自己。
3. 经过：按发生的顺序讲，一页一个阶段。做错的那次要写，写出错在哪、后来怎么发现的。
4. 要是重来一次：只写一两条真正会改的做法，写不出就不写这一页。
5. 清单页（有的话）：要带的东西、要办的事，这类真正并列的内容才用列表或步骤。

## 这类稿子容易出的毛病

- 把经过写成「三个建议」「五个要点」。读者要的是你那一次的经过，要点自己会总结。
- 只写顺利的部分。没出过岔子的经验读者不信，也用不上。
- 「一定要」「千万别」满篇都是。只在你真吃过亏的地方用，并写出那次亏在哪。
- 把花的钱、用的时间藏起来。这两样是读者最先找的。

> 「合同一定要仔细看」→「合同里写的是押一付三，我签完才发现中介费另算一个月，多付了 2800。」

## 小红书正文与话题

正文说清楚这是哪一年、哪个城市、什么情况下的经验，政策和价格会变的地方提一句以当时为准。话题用具体的：#一个人搬家 比 #生活 好找。
